## What the portfolio covers

- Confirmed employment, freelance availability, and completed education
- Evidence-based technology groups without arbitrary proficiency percentages

## Content policy

- Name and link only public repositories.
- Private repositories may inform aggregate technology labels, but their identities, code, architecture, clients, and metrics must never be published.
- Link public contributions to authored commits or pull requests.
- Keep merged, open, closed-unmerged, and collaborator work clearly separated.
- Update the underlying GitHub truth document before making future employment or portfolio claims.

Public source of truth: [`docs/GITHUB_TRUTH.md`](docs/GITHUB_TRUTH.md)
